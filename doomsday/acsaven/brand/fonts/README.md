# Acsaven brand fonts

**Inter** (SIL OFL 1.1) is the family wordmark font — same look on every device.

- Runtime (same-origin only): `Inter-Bold.woff2`, `Inter-ExtraBold.woff2`
- SVG generation: `Inter-Bold.ttf` via `npm run gen:brand`
- License: `OFL-Inter.txt`

Body UI stays on the system stack. Never load fonts from Google Fonts or other CDNs.
