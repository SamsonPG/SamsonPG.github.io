```
Name first: **TryTokka is not TikTok.** It’s an AI API spend monitor from Acsaven.

## The problem

If you ship with OpenAI, Anthropic, Gemini, OpenRouter (and friends), the invoice is split across dashboards. A spike shows up as a card charge, not a calm Slack ping.

## What TryTokka does

https://trytokka.com/

- Sync spend across providers into one view  
- **Scout** emails when you cross the limit you set — after daily sync (~24h), or use **Sync now** for same-day numbers  
- See what caused a spike (model-level)  
- Model savings hints  
- Read-only keys, AES-256 encrypted  

Not a proxy. Not a chat-app session meter. Invoice-oriented.

## Pricing

- Free forever: limited after trial (1 provider, dashboard)  
- Solo: $9/mo  
- Team: $29/mo  
- 7-day free trial, no credit card  

## Stack (for the curious)

Next.js, Supabase, Stripe/Razorpay/Dodo, Resend for Scout mail.

If you try it, tell me which provider you wish we’d sync next.
```
