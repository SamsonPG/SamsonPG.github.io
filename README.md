# samsonpg.github.io

Personal site for **Samson P G** — static HTML/CSS/JS on GitHub Pages (no build step).

## Features

- Light / Dark / System theme (same model as Acsaven / TryTokka)
- Software-first portfolio + creative media chapter
- SEO: canonical, Open Graph, Twitter, JSON-LD, `robots.txt`, `sitemap.xml`, `llms.txt`, `ai.txt`
- Performance: WebP images, no GSAP CDN, deferred JS, system UI font for body

## Local preview

Open `index.html` in a browser, or:

```bash
npx --yes serve .
```

## Deploy

Push to `main`. GitHub Pages source: `/ (root)`.
