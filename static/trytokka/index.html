The question we get asked

“OpenAI already has spend limits. Why do I need this?”

OpenAI's spend alerts cover OpenAI. Anthropic's Console covers Anthropic. Neither one knows the other exists — and OpenAI budget alerts are notifications, not a guaranteed hard stop. If you use both providers — plus Gemini, OpenRouter, Cursor, or Azure — your actual AI spend is invisible to all of them individually.

And if you're running AI agents (Cursor, Claude Code, GitHub Copilot) that make API calls autonomously overnight — provider dashboards show the aftermath. Scout emails after the next daily sync (or Sync now), usually within ~24h — not the moment a loop starts. Pair Scout with a verified kill switch if you need enforcement at night. See also how TryTokka differs from Helicone, Portkey, and LiteLLM.

Common questions

Quick answers

Is TryTokka related to TikTok?

No. TryTokka (trytokka.com) is an AI API spend monitoring dashboard for developers — it tracks eight API providers plus flat subscriptions, with daily Scout threshold alerts. It has no affiliation with TikTok, ByteDance, or any social media / short-video app. It is also not ToreTokka (toretokka.com / টরেটক্কা), a Bangladeshi news-aggregator app, not Tokka, the stranger video-chat app on Google Play and the App Store, and not Tokka Labs (tokkalabs.com), a crypto proprietary-trading firm. Searches for Tryakka, tryakka, or “try tokka” are the same product; those are misspellings of TryTokka, not a different app. A search for trytokka means this spend dashboard.

Do I need an API key to use TryTokka?

Yes — TryTokka reads provider billing/usage reports with a read-only billing or Admin key (not a proxy in your request path). OpenAI needs an org Admin key (sk-admin-…), not a project sk- key. Anthropic, Gemini, and others use their documented billing credentials. You can revoke a connection anytime.

What type of API key do I need for OpenAI?

An Admin / organization API key (starts with sk-admin-...), not a project or user key (sk-...), because usage figures are only readable with an admin credential. Create one at platform.openai.com → Settings → Organization → Admin keys, and set Permissions to Read only. That matters: an admin key with full permissions can manage projects, members and other keys, whereas a read-only one can do nothing but read — which is all TryTokka needs for the single usage endpoint it calls. Other providers (Anthropic, Gemini, OpenRouter, Azure, Bedrock, Cursor) use their standard API or billing keys.

Is TryTokka a subscription limit tracker for Claude or ChatGPT chats?

No. TryTokka monitors API and org billing spend across providers (keys you connect), with daily Scout threshold emails. It is not a menu-bar widget for chat-plan session windows (5-hour / weekly consumer caps). If you need invoice-level API cost truth for builders and teams, you are in the right place.

How do I get alerted before my AI API bill gets too high?

Set a daily or monthly dollar limit during setup. Scout checks after each sync (once daily automatically, or when you click Sync now) and emails you — usually within ~24h of crossing the limit. Not a real-time circuit breaker.

How is TryTokka different from a proxy tool like Helicone?

A proxy sits between your app and the AI provider, so every prompt and response routes through it and you have to change your API base URL in each project. TryTokka only reads your provider billing totals — no code changes, no proxy in your request path, and your prompts never leave the provider.
