## Dev.to

**Title**
```
I built TryQuickImg: compress HEIC/JPG/PNG in the browser — no upload
```

**Tags:** `webdev`, `javascript`, `privacy`, `showdev`, `productivity`

**Body**
```
Most free image converters ask you to upload the photo first. That’s fine for a meme. It’s less fine for a passport scan or an exam portal photo.

## What I shipped

**TryQuickImg** — https://tryquickimg.com/

- Compress to an exact KB target  
- HEIC → JPG (iPhone photos without a desktop app)  
- Resize + crop  
- QR (URL / WiFi / vCard)  
- Simple PDF helpers  

Processing runs in the browser after the page loads. We’re not asking for an account to squeeze a JPG.

## Why

I kept hitting “upload to convert” flows and didn’t want private pictures on random servers. Same problem for students hitting KB limits on forms.

## Stack (short)

Astro + client-side libraries (HEIC, compression, pdf-lib, QR). Deployed on Cloudflare. Parent studio: Acsaven.

## Try it

https://tryquickimg.com/compress-image/

Feedback welcome — especially if a portal’s KB rule still fights you.
```
