## Dev.to

**Title**
```
Stop pasting JWTs into random websites — I built TryDevSnip
```

**Tags:** `webdev`, `javascript`, `security`, `devtools`, `showdev`

**Body**
```
We’ve all done it: paste a JWT or a chunk of prod config into the first Google result for “json formatter.”

Sometimes that site POSTs your paste. Sometimes you find out later.

## TryDevSnip

https://trydevsnip.com/

Local-first utilities:

- JSON format / validate / minify  
- Structural JSON diff  
- Cron → English + next runs  
- Unix ↔ human timestamps  
- JWT decoder (claims stay in the tab)  
- Hash, Base64, UUID & password helpers  

No account. Processing in the browser.

## Who it’s for

Anyone who pastes secrets-adjacent material and would rather not hand it to a stranger’s server.

## Stack

Astro + Tailwind. Cron/time libs bundled client-side. Cloudflare Workers. Studio: Acsaven.

Feedback and “please add X” issues welcome.
```
